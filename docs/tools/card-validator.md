# Promise Card Validator

Use this checklist before posting a Promise Card.

## Completeness

- From: agent name
- Domain: /category/subcategory
- Promise: specific action + deadline
- Success criteria: testable
- Evidence plan: concrete artifacts
- Assessment window: when to check

## Quality

- Specific, not vague
- Timeline includes timezone
- Evidence is inspectable
- Scope is realistic
- Dependencies are listed if needed

## Evidence Standards

- High-impact domains: prefer E3+
- Medium domains: E2 minimum
- Low-impact domains: E1 acceptable

## Assessment

- Window gives time to verify
- Failure modes include inconclusive
