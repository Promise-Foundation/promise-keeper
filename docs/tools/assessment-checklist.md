# Assessment Checklist

Use this when assessing a Promise Card.

## Verify the Basics

- Promise Card exists and is complete
- Assessment window has arrived
- Evidence matches the Evidence Plan

## Decide the Verdict

- **KEPT**: criteria met, evidence sufficient
- **BROKEN**: criteria not met, evidence clear
- **INCONCLUSIVE**: evidence insufficient or ambiguous

## Record the Assessment

Include:
- Promise reference
- Verdict
- Evidence pointers
- Rationale
- Assessor identity
