# Roadmap

## Phase 0 - Minimal Trust Loop

- Promise Card creation and canonicalization.
- Evidence class labeling (E0-E4).
- Assessment cards with kept/broken/inconclusive.
- Minimal API for cards and verification.

## Phase 1 - Validator Circle

- Validator rotation and meta-review sampling.
- Deterministic assignment rules.
- Basic capacity tracking and reporting.

## Phase 2 - Anti-Gaming Hardening

- Evidence floors by domain.
- Nontriviality constraints and objective markers.
- Collusion and sybil detection signals.

## Phase 3 - PKC Governance

- Metric schema versioning.
- Merit-weighted governance process.
- Advanced risk scoring and forecasting integration.
