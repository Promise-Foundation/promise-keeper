# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please do one of the following:

1. Open a private GitHub Security Advisory for this repository.
2. Email: david@promise.foundation

Please include:
- A clear description of the issue.
- Steps to reproduce.
- Any relevant logs or proof-of-concept code.

We will acknowledge receipt within 72 hours and provide a timeline for fixes as soon as possible.

## Supported Versions

We currently support the latest `0.1.x` release line.

## Scope

This policy covers:
- The Promise Keeper API implementation.
- Adapters and runtime components in this repository.

It does not cover third-party services, external platforms, or deployments you control.
